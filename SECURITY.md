# Security Policy

## Reporting a vulnerability

Please do **not** report security problems in a public issue.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainers can see your report.

Please include what you found, the affected app and version, and steps to reproduce it. We will acknowledge your report and keep you informed about the follow-up.

## Sensitive data in issues

Never post passwords, tokens, tenant IDs or customer data in an issue. If you did so by accident, edit or delete the message immediately and rotate the affected credentials, because the content may already have been read.
